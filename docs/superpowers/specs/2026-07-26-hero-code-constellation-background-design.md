# Hero「Code Constellation」背景设计

## 目标

将首页 Hero 从通用的暗色网格与抽象节点，升级为能够表达全栈开发者身份的沉浸式代码空间。画面应传达 Java、Python、Vue 与 AI 应用开发能力，同时保持首屏标题、行动按钮和导航的清晰可读。

## 视觉方向

主视觉采用「Code Constellation」：右侧是一个半透明的运行时窗口，代码片段、语言运行时标签和 SVG 数据连线处于不同深度；它完全取代原有的泛化 3D 网络背景，成为数据底层与视觉焦点。

不使用满屏代码雨、旋转地球、强闪烁、真实 IDE 截图或大量悬浮卡片。代码片段只承担品牌语义与视觉节奏，不承载实际阅读任务。

## 画面层级

1. `hero-gradient`：保留深色画布、蓝紫光晕和轻微噪点。
2. `hero-code-field`：新增透视网格、若干低对比度代码行和沿线移动的数据脉冲。
3. `hero-code-window`：新增右侧玻璃运行时窗口，包含 Java、Python、TypeScript / Vue 的简短语法高亮片段。
4. `hero-runtime-rail`：展示 `JAVA`、`PYTHON`、`VUE`、`AI` 四个模块标签与状态点。
5. `hero-background-protection` 与 `hero-bottom-fade`：继续保障正文与下方过渡的对比度。

## 交互与动效

- 鼠标移动更新 CSS 自定义属性；运行时窗口、标签、网格和光晕以不同倍率产生轻微视差。
- 桌面端在无障碍偏好允许时，数据脉冲沿连接路径慢速运行，代码窗口中的一行出现低频扫描高亮。
- 所有背景层 `pointer-events: none`，不会遮挡链接、按钮或导航。
- `prefers-reduced-motion` 停止所有连续动画与指针位移，仅显示静态的代码窗口、标签和网格。

## 响应式与性能

- 大于等于 1024px：完整代码窗口、运行时标签与数据场。
- 768px 至 1023px：缩小窗口与标签，减少数据脉冲数量。
- 小于 768px：使用一个简化的代码窗口与两个语言标签；避免占据首屏正文区域。
- 不增加图片、视频、网络请求或新依赖；视觉资源全部由 React、SVG 和 CSS 构成。
- 不在每次 `pointermove` 触发 React 渲染，继续通过 `requestAnimationFrame` 写入 CSS 变量。

## 可访问性

- 背景语义完全标记为 `aria-hidden`。
- 代码文本不可被屏幕阅读器朗读或获得焦点。
- 静态降级画面仍保留足够的文字与背景对比度。

## 验收标准

- 首页 Hero 有明确的代码、编程语言和数据流视觉识别，但标题、说明与两个 CTA 始终优先。
- 鼠标移动可见克制的分层响应，移动端无需加载 WebGL。
- 375px、768px、1280px 不产生水平溢出。
- `prefers-reduced-motion` 下不播放背景连续动画。
- 页面可构建、类型检查通过，首页在本地服务中正常显示。
