# 企业合规基础

本阶段提供基础控制而非认证声明：租户范围过滤、哈希化 API Key、审计、DNS 域验证、SSO 配置边界、私有文件代理、AI 内容扫描、导出和备份文档。

- 隐私：公开隐私说明位于 `/privacy`；运营数据不保存原始 IP、模型密钥或完整聊天内容。
- 数据处理：部署方应与客户确认数据区域、子处理方、保留期、删除/导出流程和 incident 联系人。
- 安全：企业 API 使用最小 scope、过期、禁用和轮换；SSO 与凭据只由环境变量/Secret Store 提供；AI 文档在索引前经过高风险内容检测。
- 审计：管理员可搜索、筛选和导出事件。审计不包含原始 IP 或 secret。

SOC 2、ISO 27001、等保、GDPR/DPA、渗透测试、KMS、WAF 和灾难恢复认证需要实际的组织流程、基础设施和第三方评估，本项目不会在页面或文档中宣称已获得这些认证。
